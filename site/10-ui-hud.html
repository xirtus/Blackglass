UI / HUD / UX

The intelligence operating system is the primary art asset and control surface. The 3D world should never compete with the information hierarchy; it exists to make the data spatial and consequential.

HYDRA workspace

The second campaign should not be a green recolor of the government console. Keep the common map and entity language, but reorganize the desk around the active holder, trusted network, archive forms, credibility, branch independence, public attention and fuzzy pressure.

┌──────────────────────────────────────────────────────────────────────┐ │ ACTIVE HOLDER / CLOCK / COMMITMENTS / PUBLIC ATTENTION │ ├──────────────────┬────────────────────────────────┬─────────────────┤ │ TRUSTED NETWORK │ WORLD MAP │ ARCHIVE / PROOF │ │ trust / circles │ known contacts / destinations │ copies / forms │ │ branch health │ fuzzy pressure / public events│ credibility │ ├──────────────────┴─────────────────────┬──────────┴─────────────────┤ │ EVENTS / RELATIONSHIP HISTORY │ ACTIONS / BRANCH STRATEGY │ └────────────────────────────────────────┴────────────────────────────┘

Cross-highlighting still applies: selecting a person highlights their relationships, known copies, events and map state. Exact hidden surveillance information must remain absent.

Interaction rules

  • Hover previews; click selects; double-click or Enter focuses.
  • Every entity gets a stable ID and consistent color/state language.
  • Cross-highlighting is mandatory: selecting a person highlights their map marker, graph node, timeline events and copies.
  • Breadcrumbs must make it impossible to become lost in graph drill-down.
  • Keyboard shortcuts for pause, speed, pin, focus, back, cycle alerts and open command palette.
  • Panels collapse on smaller screens; map remains the spatial anchor.

Charts and data visualization

Use semantic HTML tables with Charts.css-style visualization for resource bars, exposure, confidence and historical trends. Use SVG or canvas for dense relationship/network plots and Three.js/deck.gl for geospatial arcs. The HUD should remain DOM-based for accessibility, responsiveness and fast iteration.

Accessibility

Never encode state only by color. Add icons/text/shape. Respect reduced motion for UI transitions, support scalable UI, keyboard navigation, tooltips, pause-anytime analyst mode and readable contrast. Provide an optional “simplified effects” mode that reduces scanlines, bloom and glitch.
