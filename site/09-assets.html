Asset Strategy

Approximately 60% of visible content should be procedural/geographic, 30% licensed library assets and only 10% custom models. Custom work is reserved for what makes the game unmistakably itself.

Procedural / data-driven — make systems, not files

Asset registry

Every external asset must enter a registry before import. Store creator, source URL, license, attribution text, acquisition date, whether modification/commercial use is permitted, model scale, triangle count, texture memory and optimization status. Prefer CC0, CC-BY or explicit commercial-friendly royalty-free licensing. Do not assume “downloadable” means shippable.

Custom art priority: UI visual language → black-program technology → hero characters → hero interiors. Generic reality comes last because our data/procedural stack already makes it.
