Technical Architecture

Use geospatial software for geography, data-oriented simulation for the game state, and Three.js only where 3D meaningfully adds to the intelligence view. Keep the simulation independent from rendering.

Dual-controller architecture

Implement both factions as command producers over one authoritative simulation. A human controller and bounded AI controller should implement the same faction-facing command interface so the opponent can later be replaced by another human without rewriting the world.

All UI selectors consume a perspective-filtered view model. The containment AI and disclosure AI must also use those filtered beliefs instead of reading hidden world truth.

Separation of concerns

The renderer must never be the source of truth. An agent exists in simulation even if it is currently an aggregate regional statistic. Rendering subscribes to derived views. Commands mutate the simulation through explicit actions that can be logged and replayed.

Repository reuse policy

Clone/fork only when license permits and the code materially shortens the build. For unlicensed or ambiguous repos, study architecture and reimplement ideas rather than copying source. Lock external code to known commits and maintain a THIRD_PARTY.md record.
